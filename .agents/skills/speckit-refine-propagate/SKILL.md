# Propagate a specification refinement

Read `.specify/extensions/refine/commands/speckit.refine.propagate.md` from the repository root and follow its workflow for the feature named by the user. Treat `$ARGUMENTS` as the user's request. Verify the spec was actually refined, inspect the affected plan and tasks, and keep the changes scoped to those artifacts. Report any remaining contract or data-model updates separately.
