# Refine an existing specification

Use the Refine extension already installed in this repository. Read `.specify/extensions/refine/commands/speckit.refine.update.md` from the repository root and follow its workflow for the feature named by the user. Treat `$ARGUMENTS` as the user's request. Confirm the target feature directory before editing, and preserve existing requirements unless the requested change calls for their revision.
